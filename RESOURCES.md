# AI-103 Resource Index

The repository intentionally separates **must-read**, **visual reference**, and **deep reference** material. Do not attempt to read every Microsoft Learn page.

## 🥇 Primary — Must Use

### Official AI-103 Study Guide
https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ai-103

Use this as the authoritative source for exam scope and skills measured.

### Official AI-103 Course
https://learn.microsoft.com/en-us/training/courses/ai-103t00

Use this as the primary learning-path source. It currently covers four learning paths: generative AI apps, AI agents, natural-language solutions, and visual-data solutions.

## 🥈 Visual / Architecture References

### Microsoft Foundry
https://learn.microsoft.com/en-us/training/azure/ai-foundry

Use when we need a platform-level mental model.

### Foundry Architecture
https://learn.microsoft.com/en-us/azure/ai-foundry/concepts/architecture

Use for architecture diagrams and component relationships.

### Azure AI Architecture Center
https://learn.microsoft.com/en-us/azure/architecture/ai-ml/ai-get-started

Use for end-to-end architecture patterns and trade-offs.

## 🥉 Deep Reference — Only When Needed

Use individual Microsoft Learn modules when a topic gate exposes a weak area. The trainer should point to the exact section rather than asking you to read an entire learning path blindly.

## Resource Rule

For every study topic the trainer will identify:

- **Read:** the exact resource/section needed.
- **Visual:** the diagram or architecture to study.
- **Build:** the hands-on task.
- **Skip for now:** lower-value material.
