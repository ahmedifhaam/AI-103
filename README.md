## Learning Philosophy

This repository is **not a documentation dump**. Each topic should be learned through:

```text
VISUAL MODEL → SHORT EXPLANATION → EXAMPLE → HANDS-ON → QUICK CHECK → TOPIC GATE
```

Text-heavy Microsoft documentation is used as a reference, not as the primary learning format.

### Topic priority

- 🔴 **MUST KNOW** — likely to materially affect exam performance
- 🟠 **SHOULD KNOW** — important for scenario questions
- 🟢 **RECOGNIZE** — know what it is and when to choose it
- ⚪ **OPTIONAL** — only if time remains

## Daily Loop

**Morning:** 5-question review of the previous session → today's visual lesson → target.

**Study:** learn in small checkpoints → complete a hands-on task → answer exam-style questions.

**End:** record score, weak areas, and completion status.

**Next session:** weak areas are reviewed before new material.
