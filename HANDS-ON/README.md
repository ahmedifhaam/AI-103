## Working rule

Hands-on work is tracked separately from study-session notes.

Each lab should record:

1. Objective
2. Real source/application used
3. Architecture
4. Setup
5. Experiment
6. Observation
7. Metric/result
8. Diagnosis
9. Remediation
10. AI-103 exam takeaway
