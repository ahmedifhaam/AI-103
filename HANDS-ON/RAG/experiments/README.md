# RAG Experiments

Each experiment gets its own folder.

Recommended structure:

```text
experiments/
├── 001-baseline/
│   └── README.md
├── 002-keyword/
│   └── README.md
├── 003-vector/
│   └── README.md
└── 004-hybrid/
    └── README.md
```

An experiment should explain what changed and what the evidence showed.

The goal is not merely to make the system work. The goal is to understand *why* retrieval behaves differently and connect the observation to an AI-103 concept.
