## Structure Rule

Each **date folder is a session-day root**. Its `README.md` summarizes what was learned that day and links to the detailed topic branches.

Each **topic file is a leaf** containing the actual study evidence: teaching approach, mental models, concepts, exam rules, examples, questions, answers, corrections, misconceptions, and gate status.

As topics become larger, a topic file may itself become a folder with its own `README.md` summary and deeper branches. Do not keep growing a single giant session file.

## Evidence Rule

Only record what was actually taught, asked, answered, corrected, or demonstrated. Never infer an answer, score, confidence, hands-on completion, or mastery.

## Progress Rule

`PLAN/02-Progress.md` is the dashboard, not the detailed transcript. It should contain concise current status, links to session roots, topic-gate state, weak areas, and next targets. Detailed session evidence belongs here.
